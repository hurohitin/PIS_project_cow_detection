Разработка системы компьютерного зрения для автоматического обнаружения и подсчёта коров в коровнике.
Выполнили студенты группы ИИ-26 Пасевич К.Ю., Хомиченко И.А., Рулько М.А.

Этап 1. Разобраться в задаче, понять ожидаемый результат и определить первые шаги работы
Что было сделано:
На начальном этапе была проанализирована предметная область. Мы определили, что задача относится к классу детекции объектов (Object Detection). Ожидаемый результат это не просто классификация изображения ("есть корова или нет"), а нахождение конкретных особей на фото с отрисовкой ограничивающих рамок (Bounding Boxes).
Был сформирован основной пользовательский сценарий: пользователь запускает программу, выбирает файл с изображением, программа обрабатывает его нейросетью и выводит результат с визуализацией.
В качестве минимально рабочей версии (MVP) было решено создать скрипт на Python, который принимает на вход картинку, обрабатывает её через предобученную модель и сохраняет результат.

Этап 2. Создать техническую основу проекта и научить программу принимать произвольное изображение
Что было сделано:
Была настроена среда разработки PyCharm, создано виртуальное окружение (.venv) для изоляции зависимостей.
Установлены необходимые библиотеки: ultralytics (для работы с нейросетью YOLOv8), opencv-python (для обработки изображений) и pillow (для работы с графическим интерфейсом).
Был создан Git-репозиторий (локально и на платформе GitHub). Для корректной работы с системой контроля версий был настроен файл .gitignore, исключающий загрузку тяжелых файлов (виртуальное окружение, датасет, результаты обучения).
Был разработан графический интерфейс (GUI) на базе библиотеки Tkinter (файл gui.py). Программа имеет понятный способ запуска (через PyCharm или терминал), позволяет пользователю выбрать произвольное изображение через диалоговое окно "Загрузить фото", передает его в обработчик и отображает результат на экране.

Этап 3. Создать первый рабочий набор данных и сделать его пригодным для обучения
Что было сделано:
Был выбран и скачан готовый набор данных (датасет) с платформы Roboflow Universe (проект "Cow Detection").
Датасет содержит 1008 изображений для обучения (train) и 72 изображения для валидации (val).
Определен формат разметки YOLO format (текстовые файлы .txt, где указаны координаты рамок и класс объекта).
Данные были структурированы по папкам (dataset/images/train, dataset/labels/train и т.д.).
Был создан конфигурационный файл data.yaml, в котором прописаны пути к данным, количество классов (nc: 1) и их названия (names: ['cow']). Возможность визуально проверить разметку обеспечивалась на этапе просмотра датасета на платформе Roboflow перед скачиванием.

Этап 4. Получить первую работающую модель, которая действительно обнаруживает животных
Что было сделано:
Было произведено дообучение (Fine-tuning) модели. В качестве базовой архитектуры была выбрана YOLOv8n (самая быстрая версия), предобученная на датасете COCO.
Обучение проводилось на CPU в течение 3 эпох (для демонстрации работоспособности пайплайна).
В ходе обучения модель достигла следующих метрик на валидационной выборке:
Precision (Точность): 98.6% (модель почти не ошибается, когда находит объект).
mAP50: 73.8% (средняя точность при пороге IoU 0.5).
Веса обученной модели были сохранены в файл best.pt.
Программа (gui.py) была интегрирована с обученной моделью. При загрузке нового изображения, которого не было в датасете, программа корректно применяет веса best.pt, находит корову, визуализирует её зеленой рамкой, подписывает класс и уверенность, а также выводит общее количество обнаруженных животных в интерфейсе.
